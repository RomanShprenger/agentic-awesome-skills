# AgentBody SEO Keyword Research

Query Google Ads keyword search volume, CPC, and competition through AgentBody.

This package uses AgentBody's current Google Ads search-volume route. Keyword ideas, difficulty, intent, SERP, competitor, trend, OnPage, and LLM workflows are outside the current capability surface.

```bash
python3 scripts/seo_client.py "AI agents" --location-code 2840 --language-code en
```

Configure `AGENTBODY_API_KEY` once using the [AgentBody Agent Quickstart](https://agentbody.io/docs/agent-quickstart.md).
